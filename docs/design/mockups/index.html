ParkPass · Mockup HTML (inspect được)

Mỗi màn dưới đây là chính artboard trên design canvas, lưu thành HTML thuần. Mở màn, bấm F12 (DevTools) → tab Elements, click vào phần tử bất kỳ: giá trị padding, gap, font-size, color, border-radius ghi thẳng trong style inline, đơn vị px CSS, khớp bảng token trong DESIGN-SPEC.md.

Cách dùng cho đúng
  1. Đối chiếu hex với bảng 2.1 để gọi đúng tên token (#0F766E → --color-brand). Không copy hex vào code.
  2. Số đo trong mockup là kết quả của token, ví dụ padding: 16px là spacing-4. Code bằng token, không hard-code số.
  3. Link giữa các màn (card → chi tiết → giỏ → thanh toán) bấm được, dùng để nắm luồng.
  4. Dải nhãn màu xám trên cùng mỗi màn là tên artboard, không phải UI.
